# Archive

History moves here so live documents stay short enough to read. Nothing in this directory is current unless an active
document explicitly incorporates it.

- When HANDOFF exceeds ten session entries, move the oldest complete entries to a dated `SESSION_LOG_YYYY_MM.md` file.
- A finished roadmap phase may move to `ROADMAP_YYYY_MM.md`; its item IDs remain reserved and unchanged.
- `P0-03` creates `plainchant-lineage.md` here with the exact source commit, copied files, relevant decisions, removed
  features, and inherited traps.
- A retired design or runbook gets one file with a first line stating when and why it moved.

Archive content remains historical evidence. Never store secrets, private manuscripts, personal paths, or sensitive
incident evidence here. Leave a one-line pointer in the live document after moving content.
