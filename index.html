An offline-first long-form writer that keeps each book in plain Markdown files and prepares a one-way EPUB handoff to Plainchant Scribe.

Open the foundation shell Read the project overview

I.The idea

A book folder contains book.txt, ordered Markdown chapters, and allowed supporting files. Those plain-text files remain authoritative and readable outside Prose.

Prose keeps a recoverable working copy in IndexedDB. The desktop shell links a real book folder through narrow commands. Finished manuscripts leave Prose as a one-way EPUB 3.3 handoff to Plainchant Scribe.

❦

II.The plan

  1. Plain-text model. Parse book.txt and Markdown chapters without rewriting untouched source.
  2. Durable editing. Recover work locally and synchronize linked folders without silent overwrite.
  3. Writing tools. Add the binder, corkboard, focused editor, notes, versions, and whole-book find.
  4. Scribe handoff. Build deterministic EPUB 3.3 output and verify it with EPUBCheck and a recorded Scribe version.
  5. Release proof. Exercise offline, browser, desktop, accessibility, security, and recovery paths.

❦

III.Where it stands today

The repository contains a trimmed static foundation shell. Multi-file projects, IndexedDB persistence, versions, library, find and replace, offline caching, native folders, Markdown ingestion, and EPUB packaging remain available for adaptation.

The Prose grammar, authoritative book-folder model, recovery contract, and writing interface are not implemented yet. The shell is development evidence, not a finished writing application.

No account, no tracking. Local-only operation is a project invariant.

❦

IV.The Plainchant Suite

  • Plainchant. The Fountain screenwriting application.
  • Plainchant Prose. Plain-text drafting for novels and non-fiction.
  • Plainchant Scribe. EPUB layout and publication after Prose hands off a manuscript.
